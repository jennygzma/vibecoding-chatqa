Found the bug! The query parameters are being double-wrapped.

**The Problem:**
Your error logs show: `GET /api/notes/activities/?params[date]=2026-02-25`

It should be: `GET /api/notes/activities/?date=2026-02-25`

**What's happening:**
In `api.ts`, you're passing:
```typescript
apiClient.get('/api/notes/activities/', { params: { date } })
```

But `apiClient.get()` already wraps its second argument in `{ params }`, so it becomes:
```typescript
{ params: { params: { date } } }
```

Which axios serializes as `?params[date]=...` instead of `?date=...`

**The Fix:**
Change the call in `api.ts` from:
```typescript
getActivitiesByDate: (date: string): Promise<DayActivities> => 
    apiClient.get<DayActivities>('/api/notes/activities/', { params: { date } }),
```

To:
```typescript
getActivitiesByDate: (date: string): Promise<DayActivities> => 
    apiClient.get<DayActivities>('/api/notes/activities/', { date }),
```
