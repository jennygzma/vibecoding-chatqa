# Earlier Roompacker annotations

`72-question-draft/` preserves the newer quality draft used as an input to the
current Focus Desk-style curation. All six original JSON files were copied
without changes before the canonical set was replaced. The 34 current questions
retain useful comparisons from it while reducing repeated retrieval questions,
using stable-ID citation specifications and adding per-session cleaning ledgers.

The original 109-question draft is separately retained in
`projects/roompacker/evidence/revisions/initial-109/`. The current per-trajectory
output.json files contain the 60 local questions from the 72-question stage.
None of these earlier representations is counted in the master.

The original raw conversations remain under `projects/roompacker/evidence/raw/`.
No review status in these earlier records confers human approval on the rewritten
canonical questions.
