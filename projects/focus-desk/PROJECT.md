# Focus Desk

Status: In Progress. Review approval pending.

A personal task and focus management app. The project requires at least four independently recorded feature conversations and at least fifty evidence-linked annotations.

## Feature sequence

1. D1: Task workspace — create, edit, complete, delete, search and filter tasks; priority, due date and estimate; local persistence.
2. D2: Focus sessions — task-linked countdown, pause/resume, finish/cancel, reload recovery and retained session history.
3. D3: Daily plan — dated task selection, ordering, daily minute budget, planned workload and completion progress.
4. D4: Insights and export — date-range summaries from retained focus history, task breakdown and CSV export.

Open each feature in a separate original conversation and finish implementation and verification before beginning the next. Keep fixes in the feature's original conversation. Preserve actual message timestamps, IDs, roles and text. Do not synthesize conversation messages or backdate records.

The combined annotation export follows ../../data/focus_desk/recording-policy.md with a minimum of 50 questions. Reference percentages are planning guidance only; every category and answer needs source support. Preserve source records separately from product files.
